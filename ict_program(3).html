Program Pembelajaran

Information and Communication Technology (ICT)

Pendahuluan Program

Program kurikulum ICT ini dirancang secara komprehensif untuk memberikan pemahaman mendalam terkait teknologi informasi dan komputasi modern.

Peserta didik diproyeksikan untuk mengembangkan kompetensi teknis melalui integrasi pemahaman teoritis serta implementasi praktik secara terstruktur.

Materi Utama Kurikulum

  • HyperText Markup Language (HTML)
  • Cascading Style Sheets (CSS)
  • JavaScript Programming
  • Hypertext Preprocessor (PHP)
  • MySQL Database Management

Alur Pembelajaran

  1. 01. Penguasaan Struktur Web (HTML)
  2. 02. Perancangan Tampilan & Tata Letak (CSS)
  3. 03. Pengembangan Interaktivitas (JavaScript)
  4. 04. Pemrograman Sisi Server (PHP)
  5. 05. Pengelolaan Basis Data System (MySQL)

Glosarium & Definisi Spesifikasi

HTML (HyperText Markup Language)
Bahasa markah standar yang digunakan untuk membangun dan menyusun fondasi struktur dokumen web.
CSS (Cascading Style Sheets)
Bahasa desain yang berfungsi mengatur tata letak, visualisasi, dan estetika elemen pada halaman web.
JavaScript
Bahasa pemrograman tingkat tinggi untuk mengimplementasikan fungsionalitas dan interaktivitas dinamis.

Pemberitahuan Akademik

Persyaratan Wajib: Seluruh siswa diwajibkan menyelesaikan setiap penugasan praktikum ICT sesuai standar kelulusan dan batas waktu yang telah ditentukan.
